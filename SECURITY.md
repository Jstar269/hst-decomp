# Security policy

This repository holds C/C++ sources and Python tools that run on your own machine against inputs you supply. It ships
no binaries and no game data.

## Reporting a problem

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Examples:
a tool that can be made to write outside its working directory, run code from crafted input, or publish private files.
Please don't open a public issue for these. You can expect an acknowledgement within a week.

Never attach game data, decrypted modules, keys or compiler binaries to a report.

Rights holders with a concern about any file in this repository can use the same private channel; see the
[README](README.md#legal).

## Supported versions

Only the current `main` branch is supported.
